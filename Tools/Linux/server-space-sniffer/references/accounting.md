# 存储统计口径

## 整盘与用户目录

`storage_monitor.py` 读取挂载与 `statvfs` 计数，合计已挂载本地文件系统；不包含未挂载分区、swap 分区或未分配空间。已用计数包含本地容器数据，不能再叠加 Docker 根目录大小。普通用户可用空间不含保留块，因此总容量可大于已用加可用。

`scan_data.sh` 对 `/data` 执行一次 Dust 扫描，默认统计实际分配块，包含隐藏文件、去重硬链接。`summarize_data.py` 汇总直接用户目录及 `/data/user` 下的用户目录，独立列出 `/data/docker`、`home_bak`、`www`、`lost+found`、swapfile 等其他文件。

目录名称用于归属，不根据文件 UID 识别真实创建者。共享硬链接只分配给去重后保留的一处；跨用户的共享数据如需分摊，应由用户明确规则。

符号链接到其他磁盘的目录不跟随，网络文件系统和容器 overlay 运行视图不纳入本地目录合计。扫描期间发生写入，或文件已删除但仍被打开，以及文件系统元数据等因素，都会使目录扫描与整盘计数存在差异。

## Docker

`docker_usage.py` 只采集精简 inspect 元数据，随后只读扫描 Docker 根目录，不遍历容器的 overlay 合并视图。

| 项目 | 核算方式 |
| --- | --- |
| 容器可写层 | inspect 的 UpperDir 对应底层 diff 目录 |
| 容器目录 | Docker 根目录下 containers/容器 ID，含日志和配置 |
| 容器占用合计 | 可写层加容器目录；不再次添加日志 |
| 日志 | json-file 及轮转文件，或 local 日志目录；外部驱动不计量 |
| 镜像只读层 | RootFS.Layers 推导 chain ID，通过 layerdb/cache-id 对应 diff 目录 |
| 镜像去重合计 | 所有现有镜像所引用 diff 目录的并集 |
| 镜像独有层 | 当前仅被一个镜像引用的层，不表示可回收 |
| 本地卷 | volume inspect 的 Mountpoint 对应目录；多容器共享只计一次 |
| bind mount | 只列宿主机路径和容器路径；数据由宿主机目录统计承担 |
| 其余占用 | 总量减已测得容器、镜像去重和卷数据，含 init 层、未映射层和元数据 |

容器内 UID 不代表宿主机用户。容器名称可用于识别，明确的 owner 标签保留在 JSON；没有依据时保留未归属，不猜测创建者。各镜像行含共享层，不能按行相加。

运行中对象可能在元数据采集与目录扫描之间改变。未测得的容器、镜像或卷不能视为零；检查 JSON 与 errors 文件后报告实际覆盖范围。未映射 overlay 层与已停止容器均不能直接视作垃圾数据。
